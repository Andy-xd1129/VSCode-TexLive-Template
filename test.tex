\subsection{Quadratic Formula}

一元二次方程
\begin{equation}
	ax^2 + bx + c = 0
\end{equation}
的解可以写成：
\begin{equation}
	x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}.
	\label{eq:quadratic}
\end{equation}
